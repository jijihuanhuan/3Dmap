# 3D 世界地图（可编辑球形政区图）

一个基于 globe.gl / Three.js 的 3D 可交互世界地图，支持球形与平面两种视图，可点选国家、中国省份进行编辑。

## 功能特性

- 球形 / 平面两种视图切换
- 点选国家、中国省份，修改颜色、名称、备注
- 北极圈、南极圈、四大洋标注
- 钉标记；编辑内容保存在浏览器本机（localStorage）
- 导出 / 导入 JSON 配置

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `globe.html` | 前端页面（单文件应用，依赖 CDN） |
| `china-provinces.json` | 中国 34 个省级行政区边界数据 |
| `启动.bat` | Windows 一键启动脚本 |
| `使用说明.txt` | 本地使用说明 |

## 运行方式

**Windows 一键启动**

1. 双击「启动.bat」（需已安装 Python 3）
2. 浏览器自动打开 http://127.0.0.1:8760/globe.html

**手动启动**：在本目录下运行任意静态文件服务器，例如：

```bash
python -m http.server 8760 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8760/globe.html`。

> 注意：不要直接用文件资源管理器双击 `globe.html`，浏览器会因本地文件访问限制拦截 JSON 加载。

## 技术说明

- 3D 地球：globe.gl（基于 Three.js）
- 数据处理：D3.js、topojson-client
- 世界政区、地球贴图等资源从 CDN（jsdelivr）加载，首次打开需联网

## 数据保存

编辑结果保存在浏览器 localStorage 中，可通过页面上的导出 / 导入功能备份和恢复 JSON 配置。
